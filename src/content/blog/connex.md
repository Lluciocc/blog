## Introduction

[Connex](https://github.com/Lluciocc/connex) is a modern and intuitive Wi-Fi manager for Linux, powered by NetworkManager, offering a clean interface, a full CLI mode, seamless desktop integration, VPN and proxy management, hidden network support, QR-code pairing, and even a built-in speedtest for a complete networking experience.

## Features

### Simple and modern interface

The interface is designed to be intuitive and user-friendly, making it easy to manage network connections.

### Connect, disconnect, and manage Wi-Fi networks

The tool allows you to connect, disconnect, and manage Wi-Fi networks with ease.

### Hidden network support

Connex supports connecting to hidden Wi-Fi networks that are not broadcast.

### Connection history

Connex keeps track of your connection history, allowing you to quickly reconnect to previously used networks.

### Built-in speedtest

Connex includes a built-in speedtest feature to check your internet connection speed.

### Command-line mode

Connex offers a command-line interface for users who prefer managing their network connections through the terminal.

### QR code connection

Connex allows you to connect to Wi-Fi networks by scanning QR codes, making it quick and convenient.

### Proxy system

Connex includes a proxy management system, allowing you to easily configure and manage proxy settings for your network connections.

### VPN Management

Connex provides tools for managing VPN connections, allowing you to securely connect to your VPN services directly from the application.

## Installation

To install Connex, you can use the following command:

```bash
curl -sSL https://raw.githubusercontent.com/Lluciocc/connex/master/install.sh | bash -s -- --clone
```

> **Warning:** This installation method clones the repository and installs Connex from source.

> **Important:** Connex works on most Linux distributions that support NetworkManager.
