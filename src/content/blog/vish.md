## Introduction

[Vish](https://github.com/Lluciocc/Vish) is a graphical editor for creating Bash scripts through a node-based interface. It allows users to visually design scripts by connecting nodes that represent Bash commands, logic blocks, and scripting structures.

## Screenshot

![Vish Screenshot](https://raw.githubusercontent.com/Lluciocc/vish-utils/refs/heads/main/screenshots/screenshots1.png)

## Features

### Node-based Bash scripting

Create Bash scripts visually by connecting nodes instead of writing everything manually.

### Drag-and-drop interface

Build scripts using an intuitive graphical editor designed to make scripting easier to understand.

### Script flow visualization

Vish helps you clearly visualize the logic and structure of your Bash scripts.

### Run scripts from the editor

Generated Bash scripts can be executed directly from Vish.

### Project system

Create and manage multiple scripting projects from within the application.

### Custom themes

Vish supports multiple built-in themes, including Dark, White, and Purple.

### Multi-language support

The application includes language support to make the editor more accessible.

### Settings customization

Customize the editor behavior and appearance to match your workflow.

### Educational purpose

Vish is designed to help beginners understand Bash scripting concepts visually.

## Installation

You can install Vish from Flathub:

```bash
flatpak install flathub io.github.lluciocc.Vish
```

Or download the latest AppImage from the [releases page](https://github.com/Lluciocc/Vish/releases):

```bash
chmod +x Vish-*.AppImage
./Vish-*.AppImage
```

> **Warning:** Vish is not intended to replace traditional text-based scripting, but to provide a visual and educational way to create Bash scripts.

> **Important:** Vish is mainly focused on Linux systems, with partial Windows support where some features may be limited.

## Conclusion

Vish is a personal project made to simplify Bash scripting and make script logic easier to understand. By using a visual node-based workflow, it helps beginners learn scripting concepts while still generating real Bash scripts.
