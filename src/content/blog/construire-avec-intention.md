## Start with the need

A good project does not start with a technology. It starts with a precise question: what is the person actually trying to do?

This question helps keep an interface readable and remove features that add no value. Every animation, color, and piece of spacing should serve understanding.

## Simplicity takes work

An experience that feels obvious is often the result of many choices. Components should have a clear responsibility, error states should be anticipated, and loading times should remain invisible.

```ts
const experience = {
  clear: true,
  fast: true,
  intentional: true,
};
```
